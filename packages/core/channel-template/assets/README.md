# Channel assets

Files the animation templates use for this channel.

| File          | Used for                                    |
| ------------- | ------------------------------------------- |
| `logo.png`    | Watermark and end screen                    |
| `mascot/`     | Mascot artwork (SVG or Lottie JSON)         |
| `music/*.mp3` | Background tracks — royalty-free only       |
| `fonts/`      | Only if the theme font is not a Google Font |
